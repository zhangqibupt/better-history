# Better Search Bar

一个基于 Chrome Manifest V3 的独立历史搜索页扩展。点击扩展图标后，会打开一个高密度历史检索页面，以紧凑单行列表快速展示结果。

## 功能

- 使用独立扩展页面作为主入口，不再依赖 `omnibox` 关键字模式
- 搜索覆盖标题与 URL，排序规则为“标题命中优先 > 最近访问时间 > 访问次数 > URL”
- 同一域名下若标题相同，仅保留一个代表结果
- 默认使用高密度单行列表展示结果，每条记录只显示图标、标题和 URL
- 支持 `site:domain` / `domain:domain` 显式站点定向搜索，但不再显示独立的域名筛选 UI
- 优先使用浏览器原生历史搜索做粗召回，再在本地执行排序和去重，降低全量扫描开销
- 图标优先使用 Chrome 扩展官方 `_favicon` 能力，并按页面 URL 与屏幕像素比复用缓存；失败时回退到稳定占位图标
- 点击结果后在新标签页打开目标页面，搜索页保持当前上下文，便于连续搜索

## 安装

1. 打开 Chrome 或兼容 Chromium 的扩展管理页：`chrome://extensions`
2. 开启“开发者模式”
3. 点击“加载已解压的扩展程序”
4. 选择当前仓库根目录 `/Users/bytedance/workspace/github/better-search-bar`

## 使用

1. 点击浏览器工具栏中的扩展图标
2. 插件会打开独立的历史搜索页面
3. 在搜索框输入关键词，例如 `chrome`
4. 如果只想查看某个站点，可输入 `lrm site:larkoffice.com`
5. 结果会以紧凑单行列表展示，便于快速扫描更多记录
6. 点击任意结果，在新标签页打开目标页面；当前搜索页面会保留搜索上下文

## 开发与测试

```bash
npm test
```

测试覆盖核心纯函数逻辑：查询解析、标题与 URL 匹配、排序、域名筛选、同域名同标题去重，以及新的粗召回策略。

如果你修改了扩展源码但浏览器页面仍表现异常，请回到扩展管理页重新加载该扩展，再重新打开搜索页，避免继续运行旧缓存脚本。

## 权限与限制

- 仅声明 `history` 权限，用于读取浏览历史
- 当前入口为扩展图标点击后打开的独立页面，不再支持 `hs <keyword>` 这类地址栏模式
- 搜索默认优先使用 `chrome.history.search(query)` 做原生粗召回；若结果不足，会执行受控补召回，而不是无条件全量扫描
- 结果图标通过 Chrome 扩展官方 `favicon` 权限与 `_favicon` 资源获取，尽量与浏览器历史页保持一致；若不可用，则回退到稳定的首字母占位图标
- 当前界面优先追求高密度检索体验，因此默认不展示域名分组卡片和显式筛选面板
