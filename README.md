# Better History

一个基于 Chrome Manifest V3 的独立历史搜索页扩展。点击扩展图标后，会打开一个高密度历史检索页面：默认展示最近访问记录；输入搜索词后，再按相同 icon 来源自动分组展示结果，帮助你更快识别目标来源。

## 功能

- 内置一套独立品牌 logo：用“搜索镜 + 时钟”的组合图形表达高效历史检索，工具栏图标与扩展详情页图标保持一致
- 使用独立扩展页面作为主入口，不再依赖 `omnibox` 关键字模式
- 搜索覆盖标题与 URL，排序规则为“标题命中优先 > 访问次数 > 最近访问时间 > URL”
- 同一域名下若标题相同，仅保留一个代表结果
- 输入搜索词后，结果会按相同 icon 来源自动聚集排序；在实现上采用站点级 favicon 来源做低成本近似，因此 `*.larkoffice.com` 会自然排在一起
- 每个分组内部继续使用高密度单行记录，并优先完整展示标题，URL 作为辅助信息显示
- 支持 `site:domain` / `domain:domain` 显式站点定向搜索，但不再显示独立的域名筛选 UI
- 优先使用浏览器原生历史搜索做粗召回，再在本地执行排序和去重，降低全量扫描开销
- 页面初次打开且输入为空时，会先展示最近访问的 20 条去重记录，并按上次访问时间倒序排列，不做分组或快捷筛选
- 图标优先使用 Chrome 扩展官方 `_favicon` 能力，并按页面 URL 与屏幕像素比复用缓存；失败时回退到稳定占位图标
- 会过滤 `doubao://history` 这类内部历史页结果，避免污染搜索结果
- 当结果存在多个可解释分组时，会在结果区上方显示更轻量的站点快捷筛选条，默认只展示 favicon 和分组标题
- 站点快捷筛选条支持鼠标点击，也支持 `Ctrl + 数字键` 快速切换；默认界面不显示数字映射，按住 `Ctrl` 时会在 chip 右上角以悬浮徽标形式临时显示，不会引起 chip 宽度跳动
- 当前筛选对应的结果数会显示在状态栏文案里，而不再堆叠在每个 chip 上
- 搜索词变化时，若当前站点筛选在新结果里仍然有效，则继续保留；只有显式切回“全部结果”或筛选失效时才清除
- 支持键盘结果导航：`ArrowUp` / `ArrowDown` 切换当前选中结果，`Enter` 在当前标签页打开，`Shift+Enter` 在新标签页打开；键盘选中不会被鼠标悬浮抢占，且会自动滚动到更合适的可视区域
- 支持扩展级快速唤出快捷键：默认 macOS 为 `Cmd + Shift + E`，Windows/Linux 为 `Ctrl + Shift + E`
- 鼠标点击结果时不会抢走搜索输入框焦点；当搜索页重新回到前台时，输入框会自动恢复焦点，方便继续使用上下键导航
- 鼠标点击结果仍保持既有语义：在新标签页打开目标页面，搜索页保持当前上下文，便于连续搜索

## 安装

1. 打开 Chrome 或兼容 Chromium 的扩展管理页：`chrome://extensions`
2. 开启“开发者模式”
3. 点击“加载已解压的扩展程序”
4. 选择当前仓库根目录 `/Users/bytedance/workspace/github/better-search-bar`

## Logo 设计

- 设计目标：让图标在 Chrome 工具栏的 16px 小尺寸下，依然能快速传达“搜索历史”的产品语义
- 图形语义：主体是放大镜，镜片内部用钟表指针表达“History”，手柄末端做了轻微箭头处理，补充“快速跳转 / 导航”的感觉
- 视觉风格：延续搜索页现有的 indigo 主色，使用深浅渐变提高识别度，并通过高对比白色图形确保小尺寸可读性
- 资源位置：矢量源文件位于 `assets/logo.svg`，导出后的扩展图标位于 `assets/icon-16.png`、`assets/icon-32.png`、`assets/icon-48.png`、`assets/icon-128.png`
- 接入方式：`manifest.json` 已声明 `icons` 与 `action.default_icon`，重新加载扩展后即可看到新 logo

如果后续你想继续迭代 logo，建议只修改 `assets/logo.svg`，再用 macOS 自带的 `sips` 重新导出各尺寸 PNG：

```bash
for size in 16 32 48 128; do
  sips -s format png -z "$size" "$size" assets/logo.svg --out "assets/icon-${size}.png"
done
```

## 使用

1. 点击浏览器工具栏中的扩展图标
2. 插件会打开独立的历史搜索页面
3. 页面会先展示最近访问的 20 条去重记录，并按上次访问时间倒序排列
4. 在搜索框输入关键词，例如 `chrome`
5. 如果只想查看某个站点，可输入 `lrm site:larkoffice.com`
6. 只有在你输入搜索词之后，结果形成了多个可解释的站点分组时，结果区上方才会显示快捷筛选条；点击 chip 或按 `Ctrl + 数字键` 可以快速切换分组
7. 快捷筛选条默认只展示 favicon 和站点名；按住 `Ctrl` 时，会在 chip 右上角临时显示数字提示，不影响 chip 宽度
8. 当前筛选和对应结果数会显示在状态栏里，例如“当前筛选：larkoffice，显示 9 条”
9. 当你继续修改搜索词时，只要当前筛选分组仍存在，系统会继续保留该筛选
10. 使用 `ArrowUp` / `ArrowDown` 切换当前选中结果，选中项会有更明显的高亮，鼠标悬浮不会打断键盘选中，搜索框也会保持在视口顶部
11. 按 `Enter` 会直接在当前标签页打开选中结果
12. 按 `Shift+Enter` 或直接鼠标点击任意结果，会在新标签页打开目标页面；当前搜索页面会保留搜索上下文
13. 也可以直接使用扩展快捷键快速唤出搜索页：macOS 默认是 `Cmd + Shift + E`
14. 如果想修改默认快捷键，可以打开 `chrome://extensions/shortcuts` 自定义 Better History 的命令
15. 当你从新打开的页面切回搜索页时，输入框会自动恢复焦点，可直接继续输入或使用上下键

测试覆盖核心纯函数逻辑：查询解析、标题与 URL 匹配、排序、域名筛选、同域名同标题去重、站点分组策略、站点快捷筛选模型、键盘选择索引边界，以及当前标签页 / 新标签页两种打开路径。

## 权限与限制

- 声明 `history` 与 `favicon` 权限，用于读取浏览历史和获取更接近浏览器历史页的图标
- 当前入口为扩展图标点击后打开的独立页面，不再支持 `hs <keyword>` 这类地址栏模式
- 扩展快捷键通过 `commands` 能力提供，默认值可能受浏览器策略或本机冲突影响；若未生效，请到 `chrome://extensions/shortcuts` 手动确认或修改
- 搜索默认优先使用 `chrome.history.search(query)` 做原生粗召回；若结果不足，会执行受控补召回，而不是无条件全量扫描
- 结果图标通过 Chrome 扩展官方 `favicon` 权限与 `_favicon` 资源获取，尽量与浏览器历史页保持一致；若不可用，则回退到稳定的首字母占位图标
- 当前界面优先追求高密度检索体验，因此分组默认自动展开，不引入额外筛选、展开或切换视图操作
